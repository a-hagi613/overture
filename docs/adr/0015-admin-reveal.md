# Admin is a separate host; personal data needs a time-boxed, audited Reveal

The admin lives on `admin.tryoverture.com` behind Cloudflare Access, the owner role and a passkey assertion within 12 hours. User metadata is visible; resumes, Facts, mail and Snapshots need a Reveal: passkey, typed reason, 15 minutes, one user, audited off-box and shown to the user under "Support access". EEO answers are shown only in aggregate; card data never.

## Considered Options

- Command-line-only support: too slow for real support work.
- Full visibility without Reveal: no accountability for looking at a person's job search.
