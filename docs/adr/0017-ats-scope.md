# Simple ATSes only: Greenhouse, Lever, Ashby first

M1 applies through Greenhouse, Lever and Ashby; M2 adds SmartRecruiters, Recruitee, Workable and Personio, each only after a 20-form probe. ATSes that need a candidate account per employer (Workday, iCIMS, Taleo) are out of scope. hiring.cafe is never fetched; an import seam accepts a file of tags the owner provides.

## Considered Options

- Workday-class ATSes: an account per employer, which needs passwords Overture does not store.
