# Users never see a browser or solve a challenge

Overture is fully automatic. Prevention (stealth, residential IP, one profile per user), verification codes read from the job-search address, and the vendor's solver handle challenges; anything still blocked becomes "Couldn't apply", not charged, with one retry before Submit. The only thing a user is asked mid-pipeline is a Review. The admin can watch the vendor's live view and replay; users cannot.

## Considered Options

- A user-facing Live Tab (CDP screencast) for solving challenges: turns an automatic product into a chore and needs the user present.
