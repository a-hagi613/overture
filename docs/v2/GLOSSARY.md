# Overture v2 glossary

Replaces the v1 `GLOSSARY.md` at the repo root once the burn commit lands. Updated 2026-11-19 for Session 3.

## Language

**Posting**:
A job opening published by an employer on an ATS.

**Application**:
One attempt to apply to one Posting on the user's behalf, from preparation to the employer's final answer.

**Stage**:
Where an Application stands with the employer, shown as a Board column: Queued, Applied, Screening, Interviewing, Offer, Closed.

**Status**:
Where an Application stands inside Overture: preparing, needs review, ready, sending, sent, couldn't apply (failed), skipped, withdrawn. Separate from Stage.

**Queued**:
The first Stage: prepared and waiting to be sent, or waiting on a Review.

**Review**:
A factual question Overture will not guess at and needs the user to answer before some Applications can be sent. Answering it once unlocks every Application that asks it.
_Avoid_: Hold, review item, CAPTCHA review

**Couldn't apply**:
An Application that was not sent after its attempts (for example the site blocked it). It never uses one of the user's applications.

**Applications left**:
How many more Applications the user's plan allows; one is used only when an Application is actually sent.
_Avoid_: credit (in user-facing copy)

**Match score**:
0–100 fit between a Posting and the user's resume and targets, with a one-line reason. "Strong match" at 80 or above.

**Check-in**:
A one-tap prompt on Home asking what happened with an Application that has been in Applied for 21 days with no employer email.

**Fact**:
Something true about the user that answers application questions (work authorization, notice period). Factual answers come only from Facts.

**Question catalog**:
Every application question Overture has seen, shared across all users without their answers, each linked to the Fact that answers it.

**Job-search address**:
The address Overture gives each user on mail.tryoverture.com for their applications; employers reply to it, and the user reads and replies in Inbox.
_Avoid_: alias, real-email mode (retired)
