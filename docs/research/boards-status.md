# Boards to redraw

Moved from `DESIGN.md` §13 on 2026-11-23, when DESIGN.md became the design-system contract and this file became
the working list of boards still to draw or redraw. Product changes since the boards were drawn live here so the
contract stays readable.

The boards are a reference for visual treatment, not the source of product truth. Each change is redrawn on the
canvas before the slice that builds that screen, then built to match. Words, structure and behaviour follow
`docs/SPEC.md`; tokens and components follow `DESIGN.md`. When there is no board for a screen, build from
`DESIGN.md` and the shared components rather than inventing one, and add the gap to the table below.
