# QA layout, responsiveness, a11y and canvas parity (Audit B, #302)

Audit only; no product code changed. Measured on `origin/main` 9b506e1 with the e2e seed (owner + sample ledger +
3 notifications), built `dist`, headless Chromium, 20 routes × widths 390/768/1024/1280/1440/1920 × light/dark
(240 page loads, screenshots + DOM metrics + axe-core WCAG 2.1 A/AA). The sweep script is a throwaway
(`test/e2e/.tmp`, ignored); ticket G1 turns it into a permanent guard.

## Summary

- **Overflow:** no route overflows horizontally in the measure, but only because `AppShell` wraps everything in
  `overflow-hidden` (`src/web/app.tsx:58`), which hides overflow instead of preventing it. The owner's wide-screen
  scrollbar did not reproduce headless; the guard must measure descendants' right edge, not just `scrollWidth`.
- **Sidebar is `position: static`** on every route; it scrolls away with the page (Home, Profile, Settings all scroll it
  off by 300–400 px). Its bottom block (usage card + avatar) is pushed to the very end of the page, which is the
  "wrong looking" bottom section.
- **Pointer cursor:** Tailwind v4 preflight sets `cursor: default` on `button`. 15 distinct button styles across
  Home, Ready, Board, Review, Notifications, Profile, Search, Settings measure `default`. Links are fine.
- **Canvas leaks:** 21 `fig. N` / `folio 01` strings plus ordinals and a "Resume §2" fragment ship (list below).
- **Fake live data:** sidebar, rail and tab-bar badges are hardcoded sample strings (2 / 4 / 3) while Home shows 0.
- **Invisible button labels:** `text-btn-ink` is not a defined token, so two primary buttons render black on black.
- **a11y:** axe reports 0 violations on all 140 scans (contrast included, light 20 routes × 6 widths + dark at 390).
  Remaining defects are ones axe cannot see: touch targets, heading/landmark gaps, focus order notes below.

## 5. WCAG 2.1 AA

- **Contrast (1.4.3):** axe clean on all scans; DESIGN pairs `signal-text` and `muted-foreground` are above 4.5:1.
- **Landmarks (1.3.1/2.4.1):** every route has one `main`. Missing: no skip link (2.4.1); `/search` and `/admin*` have no
  `header`; `/board` has **2 `h1`** (page + sheet); `/admin*` have **0 `h1`** (2.4.6); `/profile` has 3 `nav`s, two of
  them need distinct labels (they have `aria-label`, verify).
- **Labels (4.1.2):** nav badges' text "2/4/3" are announced inside links without context; once live, give the link a
  count in its accessible name.
- **Target size (2.5.5 is AAA; DESIGN §7 requires 44 px on touch):** see table 2.
- **Keyboard (2.1.1/2.4.3):** global focus ring present. To verify in the fix pass: collapsing sidebar button is first
  tab stop before nav; Board sheet and Settings dialogs trap and restore focus. Not exercised by this sweep.
- **Reduced motion (2.3.3):** not measured; add `prefers-reduced-motion` to the baseline below.

## 6. Fix tickets

Order matters: B0 first (small, unblocks all), then the rest in parallel except where noted.

**B0. Global CSS baseline** (below). Scope `src/web/styles.css`, `app.tsx`. AC: all buttons pointer, disabled
not-allowed, one focus ring, no root `overflow-hidden`, `overflow-x: clip` on the shell. Proved by G1 + G3.

**B1. Fixed sidebar and bottom block.** Scope `app.tsx`, `board-rail.tsx`. Make `aside` `sticky top-0 h-dvh
self-start` with nav scrolling inside if short and the usage card + avatar pinned to its bottom; rail likewise
at 768–1279; main gets `min-w-0`. AC: after `scrollTo(0, 400)` the aside `getBoundingClientRect().top === 0`
on Home, Profile, Settings at 768/1024/1280/1920, and the avatar row bottom is within the viewport. Guard: G4.

**B2. Breakpoints per DESIGN §4.** Scope `app.tsx`, `styles.css`. Rail 768–1279, 268 sidebar from 1280, 300 + 64
padding from 1700, content max width. AC: sidebar width matches design at each width; G1 clean; board-match at
768/1280/1920 for Home. Guard: G1 + G4 width assertions.

**B3. Profile tabs scrollbar.** Scope `routes/profile.tsx`. Remove `-mb-px`/set `overflow-y: hidden` (or `overflow-x: auto;
overflow-y: clip`) and drop ordinals. AC: no element on Profile with `scrollHeight > clientHeight` and `overflow-y:auto`

**B4. Remove canvas annotations.** Scope `copy.ts` keys and all render sites in table 3, delete `SectionHead.folio`

## 7. Guard tests

**G1: no horizontal overflow, every route, every width** (`test/e2e/layout-overflow.test.ts`). For each
route in a single `routes` list (also asserted to equal the router's paths, so new routes cannot skip it) × widths
`[390,768,1024,1280,1440,1920]` × themes: `documentElement.scrollWidth <= clientWidth`, `body.scrollWidth <= clientWidth`,
and no visible element whose `getBoundingClientRect().right > clientWidth + 1` unless inside an ancestor with
`overflow-x:auto|scroll` marked `data-scroll-region`. Requires removing root `overflow-hidden` (B0) or it proves nothing.

**G2: no canvas annotation ships** (`src/shared/copy.test.ts`, unit, plus a build step). (1) Walk the exported `copy`
object (call function values with sample args) and fail on `/\bfig(ure)?\.?\s*\d|\bfolio\b|§|\bartboard\b|\bboard note\b/i`
and on keys named `fig*`/`folio*`; (2) after `bun run build`, grep `dist/**/*.{js,html}` for the same patterns
and for `copy.sample` strings; (3) an allowlist file with reasons for anything intentionally kept.

**G3: interactive affordances** (`test/e2e/interactive.test.ts`). Per route at 390 and 1280: every visible `a[href]`,
`button`, `[role=button|tab|switch]`, `summary`: `cursor: pointer` (not-allowed if disabled); hover applies a
changed `background-color|color|border-color|box-shadow|opacity` (use `locator.hover()` and compare computed
style; skip elements with `data-no-hover`); `focus()` via keyboard gives non-`none` outline width ≥2 px; at 390 the
box is ≥44×44 (inline text links excepted). Output the exact miss list on failure.

**G4: sidebar stays fixed** (inside G1's loop): on routes taller than the viewport at ≥768, scroll to 400 and
assert aside `top === 0` and its bottom block inside the viewport; assert sidebar width per DESIGN §4.

**G5: no unexpected scrollers** (G1 loop): visible elements with `overflow auto|scroll` and content larger than
box must carry `data-scroll-region`; this is what catches the Profile tabs bar.

**G6: tokens defined** (`src/web/theme-tokens.test.ts`): extract `(text|bg|border|ring|fill|stroke)-<token>`
classes from `src/web` and assert each token exists in `@theme` in `styles.css` (catches `btn-ink`).

**G7: landmarks and headings** (G1 loop + axe): exactly one `h1`, one `main`, skip link first focusable; axe
`wcag2a/aa/21aa` with zero violations on every route/width/theme.

Cost: G1–G7 are one Playwright file looping routes; run light + dark at 390/768/1280/1920 on every PR and the full
width list nightly, since the sweep took ~12 min of the shared `heavy` slot for 240 loads.

## 8. Proposed global CSS baseline (`styles.css`, after the `body` rule)

```css
/* Baseline per DESIGN.md §7 and §Buttons. Tailwind v4 preflight sets button cursor:default. */
:where(a[href], button, [role="button"], [role="tab"], [role="switch"], summary, select,
       label[for], input[type="checkbox"], input[type="radio"], input[type="file"]) {
  cursor: pointer;
}
:where(button:disabled, [aria-disabled="true"], input:disabled, select:disabled) {
  cursor: not-allowed;
  opacity: 0.45;
}
:where(a[href], button, [role="button"], summary, select):not(:disabled):not([aria-disabled="true"]):hover {
  /* components add their own surface; this keeps a visible default for unstyled ones */
  text-decoration-color: currentColor;
}
:focus-visible {
  outline: 2px solid var(--color-foreground); /* ink, never orange */
  outline-offset: 2px;
}
html { overflow-x: clip; }
body { min-width: 0; overflow-wrap: break-word; }
img, svg, video, canvas { max-width: 100%; }
@media (hover: none) { /* no sticky hover on touch */ }
@media (max-width: 767px) {
  button, [role="button"], [role="tab"] { min-height: 44px; }
}
@media (prefers-reduced-motion: reduce) {
  *, ::before, ::after { animation-duration: .01ms !important; transition-duration: .01ms !important; scroll-behavior: auto !important; }
}
```

and in `app.tsx`: drop `overflow-hidden` from the shell wrapper, use `aside … sticky top-0 h-dvh self-start`, and `main`
`min-w-0`. `html { overflow-x: clip }` hides nothing silently: G1 measures descendants, not the document.
